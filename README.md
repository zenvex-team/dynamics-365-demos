# Dynamics 365 and Power Platform demos

Working examples from ZENVEX GLOBAL: Dynamics 365 CE (Sales, Customer Service, Field Service), Power Automate and Power BI.

Everything here is built from scratch on demo data for a fictional company. No client code, data or names.

## What's inside

| Folder | What it shows |
|---|---|
| `health-check/` | Checks we run in a Dynamics 365 Health Check (read-only), with a sample report |
| `power-automate/` | Approval and error-handling flow patterns, exported as solutions |
| `pcf-controls/` | PowerApps Component Framework controls for model-driven apps |
| `field-service/` | Work order and scheduling automation examples |
| `power-bi/` | Sample reports on Dataverse data |

Each folder has its own README with a screenshot or GIF and setup steps.

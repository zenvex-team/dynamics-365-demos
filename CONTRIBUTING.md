# Rules for contributors

1. Commit as the company only:
   git config user.name "ZENVEX Solutions"
   git config user.email "357389082+zenvex-global@users.noreply.github.com"
2. No personal names, employers, client names, client data or code from any other job.
3. Build everything fresh on demo data (fictional company "Northwind Field Services").
4. Every folder needs a README with what it does, a screenshot/GIF, and setup steps.
5. No secrets: no passwords, keys, tenant IDs or connection strings in commits.
